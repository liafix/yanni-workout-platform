## Critical implementation rule

The redesign PNG is a VISUAL TARGET.

The matching WebP background is an ATMOSPHERIC / 3D BACKGROUND PLATE.

Do NOT implement the complete redesign screenshot as one background image.

These elements must remain real HTML/CSS/JavaScript:
- typography
- buttons
- navigation
- Rack Rail
- metadata
- links
- cards/panels where interaction or responsiveness requires them
- hover/focus states
- mobile menu
- accessibility semantics

If a redesign reference contains AI-generated facts, logos, prices, participant counts, sponsors, results, testimonials, or other unverified data, DO NOT copy them.
